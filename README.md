# Steam Achievement Manager — Qt 6

Steam Achievement Manager (SAM) — лёгкая портативная программа для управления
достижениями и статистикой игр в Steam. Нужен запущенный клиент Steam с выполненным входом.

Это порт [оригинального SAM](https://github.com/gibbed/SteamAchievementManager)
(Rick «gibbed», лицензия zlib) с WinForms (.NET) на C++/Qt 6, стиль Fusion.
Работает как оригинал: `SAM.Picker.exe` показывает список ваших игр,
`SAM.Game.exe <AppID>` управляет достижениями и статистикой одной игры.

Версии порта ведутся отдельно от оригинала: номер версии и версия оригинала, на которой
основан порт, — в `version.cmake`, история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Что нового по сравнению с оригиналом

- Стиль Fusion с тёмной темой «Dark Modern» и светлой (следует за Windows
  или выбирается вручную). Тема «Как в системе» берёт акцентный цвет Windows,
  выбранные вручную светлая и тёмная — синие. Скруглённые меню, панели и списки,
  у каждого раздела достижений своя карточка; свой заголовок окна — иконка слева,
  название по центру, кнопки окна справа.
- Таймер в шапке игры: сколько времени Steam считает игру запущенной.
- Плавная прокрутка колесом мыши и полосы прокрутки в стиле Telegram: тонкие, лежат
  поверх содержимого (не сдвигают его), появляются при прокрутке или наведении и плавно гаснут.
- Все настройки — в меню ☰ окна со списком игр; открытые окна игр подхватывают
  изменения сразу.
- **Выбор языка достижений** (меню ☰ → «Язык достижений»): по умолчанию язык Steam;
  если у игры нет выбранного языка, используется язык Steam.
- Интерфейс на русском и английском (меню ☰ → «Язык интерфейса»).
- Список игр плитками: обложки грузятся параллельно и кэшируются на диске,
  размер плиток меняется ползунком или Ctrl + колесом мыши, поиск по названию или App ID,
  контекстное меню (страница в магазине, библиотека Steam, копирование ID).
- Время в игре на обложке (часы и минуты) и сортировка: по названию, недавние,
  по времени в игре. Можно скрыть игры без достижений Steam (меню фильтра).
  Время и дата запуска берутся из локальных файлов Steam, без сети.
- Список игр с прошлого запуска показывается сразу, свежий скачивается в фоне.
- Менеджер: шапка с обложкой и прогрессом, поиск по названию/описанию/ID,
  фильтр «Все / Не получены / Получены / Изменённые», бейджи
  «будет получено / будет снято / защищено / скрытое», иконка меняется вместе с галочкой,
  множественный выбор (Space переключает выделенные), двойной клик переключает строку.
- **Редкость достижений**: колонка с долей игроков Steam, у которых есть достижение
  (редкие, меньше 5 %, — золотым). Данные из открытого Web API Steam, кэшируются на пару дней.
  Список сортируется по любой колонке щелчком по заголовку, третий щелчок возвращает
  исходный порядок.
- **Прогресс достижений**, которые выдаются за показатель статистики («проехать
  10 000 миль»): «6 412 / 10 000» и полоска; через контекстное меню можно перейти
  к этому показателю. Steam сам выдаёт такое достижение, когда показатель доходит до нужного
  значения, но получение достижения показатель не меняет — об этом предупреждает бейдж
  «показатель отстанет». По желанию (меню ☰ → «Поднимать связанный показатель…», по умолчанию
  выключено) показатель поднимается вместе с достижением и возвращается, если отметку снять;
  защищённые показатели, показатели, которые меняет сервер игры, и те, что Steam не даст
  изменить за одно сохранение, не трогаются — у таких достижений бейдж «показатель не поднять»
  и причина в подсказке. На вкладке статистики у каждого показателя видны допустимый диапазон
  и ограничения.
- **Разделы по DLC и обновлениям**: достижения разбиты на сворачиваемые разделы
  «Основная игра», отдельные DLC и обновления, у каждого свой прогресс. Steam этих данных
  не хранит, поэтому они берутся с [SteamHunters](https://steamhunters.com/).
  Отключается в меню ☰ (тогда запросы не отправляются).
- **Игра в статусе Discord** (меню ☰ → «Показывать игру в Discord», по умолчанию выключено).
  Discord узнаёт игры по запущенным exe, поэтому SAM запускает пустой процесс `SAM.Stub.exe`
  под именем exe игры (берётся из списка игр Discord) в `%LOCALAPPDATA%\SAM\SteamAchievementManager\discord\`.
  Процесс ничего не делает и завершается вместе с окном SAM. Работает для игр, которые знает Discord.
- Перед сохранением показывается сводка изменений; при закрытии с несохранёнными
  изменениями программа спрашивает, что с ними делать.
- Статистика: подсветка изменённых значений, проверка диапазона min/max из схемы,
  «Вернуть исходное значение» в контекстном меню.
- 64-битная сборка (`steamclient64.dll`).

## Сборка

Нужны Visual Studio 2026 с нагрузкой «Разработка классических приложений на C++»
и Qt 6.10+ для MSVC x64 (модули Widgets, Network, Svg, Qt Linguist).
Переменная `QT6_HOME_64` должна указывать на Qt, например `C:\Qt\6.10.0\msvc2022_64`
(сборки Qt для MSVC 2022 совместимы с компилятором VS 2026).

```bat
build.bat          :: Release → папка release\
build.bat debug    :: Debug   → папка release-debug\
```

Батник сам находит VS 2026, собирает проект (CMake + Ninja) и копирует рядом
с exe всё нужное из Qt — папку `release` можно переносить куда угодно.
Нужен установленный Microsoft Visual C++ Redistributable 2015–2022
(обычно уже стоит вместе со Steam).

Можно открыть папку в Visual Studio или Qt Creator — используются пресеты из `CMakePresets.json`.

Иконка: исходник `resources/SAM.svg`, в сборку попадает `resources/SAM.ico`
(и в exe, и в окна программы).

Перевод: после изменения строк в коде выполните
`cmake --build build\release --target update_translations` и заполните
`translations/sam_ru.ts` (например, в Qt Linguist).

## Где хранятся данные

- Настройки: `%APPDATA%\SAM\SteamAchievementManager.ini`
- Кэш картинок и списка игр: `%LOCALAPPDATA%\SAM\SteamAchievementManager\`
